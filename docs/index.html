Introduction

The purpose of this project is to provide an example where data from SQL Server is linked to RStudio environment. There are situation where R users does not feel confortable working with SQL. To facilitated this problem R has different solutions to amelianate this inconvenience. On of this is to stablish a connection to SQL data provider, in this case SQL Server, and access the different tables included in the schema of the database.

Data Source

The data used for the porpose of this project comes from a blog located in github called PostgreSQL Exercises. The same way, some of the exercises exposed here comes from the same source.

Connection

# Establish connection to SQL Server
con <- dbConnect(odbc::odbc(),

Exercises

Where Statement

Produce a list of facilities that charge a fee to members and that fee is less thatn 150 of the monthly maintance cost.

SELECT name, membercost, monthlymaintenance 
FROM cd.facilities
WHERE membercost>0 AND
      (membercost<monthlymaintenance/50)

Case when Statement

Create a new field that list facilities as cheap and expensive. To do that use $100 as criteria.

SELECT name, 
         CASE WHEN (monthlymaintenance > 100) THEN 'expensive'
         ELSE 'cheap'
         END AS cost
FROM cd.facilities;

Subquery

Get the first and last name of the last member who signed up.

SELECT firstname, surname, joindate
FROM cd.members
WHERE joindate = (SELECT max(joindate) 
                        FROM cd.members);

Inner Join

  • Get the list of the first six records of the start times for bookings for the member named David
SELECT B.firstname,B.surname,A.starttime 
FROM cd.bookings AS A
INNER JOIN cd.members AS B
 ON B.memid = A.memid
WHERE B.firstname = 'David' AND 
      B.surname='Farrell'

Left Join

List all members and includes those who recommended them. Order by surname and firstname

SELECT A.firstname as memfname, A.surname as memsname, B.firstname as recfname,                       B.surname as recsname
FROM cd.members AS A
LEFT OUTER JOIN cd.members AS B
 ON B.memid = A.recommendedby
ORDER BY memsname, memfname;
